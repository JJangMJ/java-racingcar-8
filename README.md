# 우테코 8기 프리코스 2주차 미션 - 자동차 경주

## 구현할 기능 목록

### 입력 기능
- **경주할 자동차 이름 압력**
  - [x] n대의 자동차 이름을 입력
    - [x] 1개 이상의 자동차 이름을 입력 받으면, 쉼표(,)를 기준으로 구분
    - [x] 쉼표와 자동차 이름 사이에 공백이 있을 경우 제거


- **자동차 경주 게임 횟수 입력**
  - [ ] 자연수를 입력
  
---

### 핵심 기능
- **자동차 경주 로직**
  - [ ] 입력받은 횟수만큼 경주 게임 진행
  - [ ] 입력받은 자동차(들)를 각각 전진하는 조건에 부합하는지 확인
    - [ ] 0에서 9사이의 무작위 값을 추출하여 그 수만큼 전진
      - [ ] 무작위 값이 4 이상인 경우 전진
      - [ ] 무작위 값이 4 미만인 경우 정지


- **우승자 추출 로직**
  - [ ] 마지막 경주까지 끝난 뒤, 가장 많이 전진한 자동차(들)를 추출
    - [ ] 가장 많이 전진한 자동차가 단독일 경우, 해당 자동차만 추출
    - [ ] 가장 많이 전진한 자동차가 공동일 경우, 공동인 자동차들을 추출

---

### 출력 기능
- **차수별 실행 결과 출력**
  - [ ] 경주에 참가하는 자동차들의 차수별 실행 결과를 차례대로 출력
    - [ ] 전진한 경우, '-' 문자를 더해서 출력
    - [ ] 정지한 경우, '-' 문자를 더하지 않고 지난 차수의 결과를 출력
    

- **우승자 출력**
    - [ ] 단독 우승인 경우, 해당 자동차의 이름을 출력
    - [ ] 공동 우승인 경우, 해당 자동차들의 이름을 출력

---

### 예외 처리
- **입력 기능 예외**
  - [x] 경주할 자동차의 이름이 5자 초과인 경우 예외 처리
  - [x] 경주할 자동차의 이름이 공백인 경우 예외 처리
  - [ ] 경주할 자동차의 이름이 중복인 경우 예외 처리
  - [ ] 시도할 횟수가 자연수가 아닌 경우 예외 처리
